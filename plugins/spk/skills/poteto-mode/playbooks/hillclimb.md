# Iterative optimization

Freeze the representative workload, metric direction, acceptance target, correctness floor and run budget. Establish that the harness distinguishes an easy workload from the actual complaint. Measure the baseline distribution.

Try one hypothesis per iteration. Record the change, measurements, correctness checks and keep/discard decision. Isolate unsuccessful attempts from user edits. Accept a win only beyond observed noise. Stop at the target, budget or a documented limit and report the best verified result.
