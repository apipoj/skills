# Authoring a skill

Identify one decision the skill should improve and a realistic near-miss. Write a concise entry point with name, description, scope and expected outcome. Put detail that applies only sometimes in a linked reference.

Resolve links from the installed layout. Run the target case, near-miss and applicable authority boundary in disposable context. Report actual behavior separately from syntax and packaging checks. For SPK, use the repository contract and generators for locale and host parity.
