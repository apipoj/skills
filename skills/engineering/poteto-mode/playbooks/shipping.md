# Shipping

Bind the target repository, base, head, payload and verdict. For a stack, walk from the lowest dependency and stop at the first unverified patch. Revalidate the base and CI when the candidate or its dependencies change.

Perform only the specifically approved merge, tag, publish or deployment. Re-read the remote result after each effect before advancing. For a release, verify the tag resolves to the tested commit and the published version matches the manifest. Report verified references and any remaining ceiling.
