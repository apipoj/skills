# Session transitions

Read only when context pressure or a requested transfer makes continuing impractical.
Continue with relevant context when possible; do not infer capacity from a fixed token count.
Use the host's supported compaction when needed, preserving scope, decisions, evidence,
unresolved work, and authority. For an explicit transfer, offer the manual `handoff` workflow;
automatic compaction does not grant permission to invoke a manual-only skill.
Clear context only when the user intends to discard it. Delegation is optional for an independent
bounded task, not a requirement at every phase boundary. Preserve completion criteria across
any transition and resume remaining authorized work.
