# Productivity — คิดและสื่อสารให้ชัด

ภาษาไทยเป็นค่าเริ่มต้น ใช้ smart defaults เมื่อปลอดภัย และรักษา approval boundary ของแต่ละ workflow

- [`ask-me`](./ask-me/SKILL.md) — ถามทีละเรื่องให้ความคิดหรือแผนชัดขึ้น สรุปให้ยืนยัน แล้วแนะนำงานถัดไปโดยยังไม่แก้ไฟล์ _(manual-only)_
- [`asking`](./asking/SKILL.md) — สัมภาษณ์ผู้ใช้เป็นรอบ ถามทุกคำถามที่พร้อมตอบในรอบเดียวพร้อมคำแนะนำ จน decision tree (แผนผังการตัดสินใจ) คลี่หมดและเข้าใจตรงกัน
- [`bala`](./bala/SKILL.md) — ใช้หลักพละ 5 เป็นเครื่องมือตรวจสอบสมดุลก่อนเริ่มงาน plan, code, review หรือแก้ปัญหา _(manual-only)_
- [`handoff`](./handoff/SKILL.md) — ย่อบริบทที่จำเป็นเป็น handoff ซึ่ง session ใหม่อ่านแล้วทำงานต่อได้โดยไม่เดา _(manual-only)_
- [`sunzi`](./sunzi/SKILL.md) — ใช้หลักซุนวูเป็น strategy lens ก่อนเลือก battle, architecture, rollout หรือ competitive move _(manual-only)_
- [`teach`](./teach/SKILL.md) — สอนแนวคิดหรือทักษะเป็นลำดับสั้น ๆ พร้อมภารกิจและหลักฐานความเข้าใจที่ใช้ต่อข้าม session ได้ _(manual-only)_
- [`to-questionnaire`](./to-questionnaire/SKILL.md) — เปลี่ยนเรื่องที่ผู้ใช้ตอบเองไม่ได้ให้เป็นชุดคำถาม Markdown สำหรับส่งให้คนที่รู้จริง โดยสัมภาษณ์ผู้ใช้เรื่องการส่ง ไม่ใช่เรื่องเนื้อหา _(manual-only)_
- [`wait-what`](./wait-what/SKILL.md) — หยุดแล้วอธิบายข้อความล่าสุดใหม่ให้เข้าใจ เติม context ที่ขาด เลี่ยงศัพท์เทคนิคที่ไม่จำเป็น และใช้คำศัพท์ของโปรเจกต์จาก CONTEXT.md _(manual-only)_
- [`write-skills`](./write-skills/SKILL.md) — เขียนหรือปรับเอกสารที่ agent ต้องอ่าน ทั้ง skill, AGENTS.md, CLAUDE.md และ doc ที่ถูกชี้ถึง ให้เรียกใช้ถูกและทำงานสม่ำเสมอ _(manual-only)_
