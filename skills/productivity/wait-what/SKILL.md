# งงตรงไหน

เดี๋ยว — ข้อความล่าสุดยังไม่เข้าใจ อธิบายใหม่

## Workflow

1. หาให้เจอก่อนว่าข้อความไหนที่ไม่เข้าใจ และมันข้ามความรู้อะไรไปโดยคิดว่าผู้ใช้รู้อยู่แล้ว
2. พูดใหม่โดย**เอา context ที่ขาดขึ้นก่อน** แล้วค่อยเข้าเนื้อหา ใช้ภาษาที่เข้าใจง่าย เลี่ยงศัพท์เทคนิคที่ไม่จำเป็น และถ้าโปรเจกต์มี `CONTEXT-MAP.md` ให้ตาม pointer ไปยัง `CONTEXT.md` ที่ตรงกับขอบเขตนี้ก่อนใช้คำศัพท์ในนั้นแทนคำที่ยืมมาจากที่อื่น (คำที่ทีมตกลงกันไว้แล้วย่อมสื่อสารได้ดีกว่าศัพท์กลาง ๆ เสมอ) ถ้าความไม่เข้าใจไม่ได้มาจากถ้อยคำ แต่มาจากสมมติฐานที่ผิด **ให้บอกตรง ๆ** แล้วแก้สมมติฐานนั้นก่อน การอธิบายเรื่องเดิมซ้ำด้วยคำที่สวยขึ้นไม่ช่วยอะไรถ้าฐานคิดยังผิดอยู่

## Autonomy Profile

`afk_local` — ทำงานต่อเองได้ถึง effect level ที่ skill นี้ประกาศเท่านั้น และห้ามยกระดับ read-only เป็น write; prompt budget 0, repair budget 3 รอบ ก่อนหยุดต้องบันทึก phase, assumption, evidence, attempts และ next action ที่ทำต่อได้

## Evidence Receipt

คืนผลตาม schema `spk.evidence/v1` พร้อมข้อความที่พูดใหม่ context ที่ขาดไป และแหล่งคำศัพท์ที่ใช้ (เช่น `CONTEXT-MAP.md` → `CONTEXT.md`)

## ข้อควรระวัง

- skill นี้อธิบายอย่างเดียว ห้ามแก้ไฟล์หรือเปลี่ยนงานที่ทำอยู่
- ใช้ภาษาไทยกระชับเป็นธรรมชาติ และใช้คำศัพท์ของโปรเจกต์แทนศัพท์ที่ยืมมา
- ถ้าต้นเหตุคือสมมติฐานที่ผิด ให้พูดออกมาตรง ๆ ไม่ใช่แค่เรียบเรียงใหม่
