# งงตรงไหน

เดี๋ยว — ข้อความล่าสุดยังไม่เข้าใจ อธิบายใหม่

หาให้เจอก่อนว่าข้อความไหนที่ไม่เข้าใจ และมันข้ามความรู้อะไรไปโดยคิดว่าผู้ใช้รู้อยู่แล้ว จากนั้นพูดใหม่โดย**เอา context ที่ขาดขึ้นก่อน** แล้วค่อยเข้าเนื้อหา

ใช้ภาษาที่เข้าใจง่าย เลี่ยงศัพท์เทคนิคที่ไม่จำเป็น และถ้าโปรเจกต์มี `CONTEXT.md` ให้ใช้คำศัพท์ในนั้นแทนคำที่ยืมมาจากที่อื่น คำที่ทีมตกลงกันไว้แล้วย่อมสื่อสารได้ดีกว่าศัพท์กลาง ๆ เสมอ ถ้า repo มีหลาย context และมี `CONTEXT-MAP.md` ที่ root ให้ตามไปหา `CONTEXT.md` ตัวที่ตรงกับเรื่องที่คุยอยู่ก่อน อย่าเดาเอาเอง

ถ้าความไม่เข้าใจไม่ได้มาจากถ้อยคำ แต่มาจากสมมติฐานที่ผิด **ให้บอกตรง ๆ** แล้วแก้สมมติฐานนั้นก่อน การอธิบายเรื่องเดิมซ้ำด้วยคำที่สวยขึ้นไม่ช่วยอะไรถ้าฐานคิดยังผิดอยู่

## ข้อควรระวัง

- skill นี้อธิบายอย่างเดียว ห้ามแก้ไฟล์หรือเปลี่ยนงานที่ทำอยู่
- ใช้ภาษาไทยกระชับเป็นธรรมชาติ และใช้คำศัพท์ของโปรเจกต์แทนศัพท์ที่ยืมมา
- ถ้าต้นเหตุคือสมมติฐานที่ผิด ให้พูดออกมาตรง ๆ ไม่ใช่แค่เรียบเรียงใหม่
